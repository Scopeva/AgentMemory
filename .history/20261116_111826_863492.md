### 关键决策与事实
- **MCP SDK 使用 2.x `MCPServer`**（不是 1.x 的 `FastMCP`）；`pyproject.toml` 依赖已更新。已确认 `mcp` 版本为 **2.3.0**。
- **服务层单点实现**：`services/core.py` 是 MCP 工具和 HTTP API 的唯一实现入口。
- **CLI 使用同步 `sqlite3`**，以避免在 pytest 已有 event loop 时 `asyncio.run()` 冲突。
- **WAL 模式**：`journal_mode=WAL` 持久设置；`foreign_keys` 和 `busy_timeout` 每个连接设置。
- **事件幂等**：`event_id` 为主键去重；`(run_id, sequence_no)` 唯一约束。
- **乐观锁**：knowledge 和 task 更新带 `revision` 条件，影响 0 行时返回冲突，不静默覆盖。
- **候选记忆与正式知识分离**：`memory_candidates`（待审）与 `knowledge`（已接受）生命周期独立。
- **uuid 在 Python 生成**（`uuid.uuid4()`），不用 `uuidgen()` SQLite 函数（非内置）。
- **BGE-M3 接入**：`config.example.toml` 中 `embedding.endpoint` 默认 `http://127.0.0.1:8001`，`provider = "bge-m3-http"`；Phase 4 实现 `BgeM3HttpProvider`。
- **Codex** 用官方 Hooks（`SessionStart` / `Stop` / `PreCompact` / `SessionEnd`）；**OpenCode** 用 Project-level Plugin；**Pi** 用 Extension。
- **Pi Extension 的 `controlled_continuation`** 能力在 `agent_capabilities.py` 中做能力协商抽象。
- **Spool 路径**：`~/.local/state/agent-memory/pi/`，每个 agent 独立子目录；at-least-once delivery，服务端返回 200/204 后才 ack 并删除。
- **防递归规则**（RunGuard）：`origin == "memory_extraction"` 拒绝再次提取；`extraction_attempted == True` 拒绝；只有 `completed/failed/interrupted` 且有 code changes 或 task significance 才触发。
- 用户环境：Orca/cmux；当前时间 2026-11-16 18:45 Asia/Shanghai。
